## Git 提交信息规则（中文）

### 提交格式
```
<类型>: <简短描述>

<详细描述>

<相关链接/Issue编号>
```

### 类型说明（中文）
- **feat**: 新功能
- **fix**: 修复 bug
- **docs**: 文档更新
- **style**: 代码格式（不影响代码运行的变动）
- **refactor**: 重构（既不是新增功能，也不是修复 bug）
- **test**: 测试相关
- **chore**: 构建/工具相关

### 示例
```
feat: 添加用户登录功能

- 实现手机号验证码登录
- 添加用户信息存储到 Redis
- 更新登录拦截器配置

Closes #123
```

### 规则
1. 提交信息必须使用中文
2. 标题不超过 50 个字符
3. 详细描述使用 Markdown 格式
4. 每行不超过 72 个字符
5. 结尾不要加句号
